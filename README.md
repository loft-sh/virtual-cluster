# Archived

This repository is the original prototype and is no longer maintained.
It does not describe how vCluster works today.

vCluster creates tenant clusters: fully isolated environments with their
own API server, CRDs and RBAC, delivered as managed Kubernetes or as the
foundation for Slurm, Ray, Run:ai and inference clusters.

Active development: https://github.com/loft-sh/vcluster
Documentation: https://www.vcluster.com/docs
